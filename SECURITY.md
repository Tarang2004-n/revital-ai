# Security & Clinical Safety Policy

## Clinical Intent & Medical Software Disclaimer
RE:VITAL AI is an experimental decision-support research platform demonstrating continuous-time temporal forecasting, adaptive conformal uncertainty bounds, and potential outcome counterfactual forks. It is **not** a cleared medical device under FDA 510(k) or EU MDR and is not intended for primary clinical diagnosis or autonomous patient triage without qualified physician oversight.

## Reporting a Security Vulnerability
We prioritize the security and integrity of clinical data pipelines and algorithms:

1. **Private Vulnerability Reporting**: If you discover a security vulnerability or algorithmic integrity flaw, please report it via GitHub Private Vulnerability Reporting or email the maintainers directly.
2. **Response SLA**: An initial acknowledgement will be provided within 24 hours, followed by a formal triage assessment within 72 hours.
3. **Disclosure Policy**: Please coordinate responsibly by allowing reasonable time for patch validation and verification prior to public disclosure.
